# Assistente com IA local — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tela "Assistente" com insights do mês e chat sobre os dados do app, respondidos por um modelo Qwen3 rodando localmente (llama.cpp como sidecar), escolhido pelo hardware e baixado no primeiro uso.

**Architecture:** O Rust (`src-tauri/src/ai.rs`) detecta o hardware, baixa o modelo, sobe/derruba o `llama-server` em `127.0.0.1` (porta e chave aleatórias, a chave nunca sai do Rust) e faz as chamadas HTTP ao servidor com `no_proxy()`, repassando a resposta ao front por `Channel`. O front (`src/ai/`) é puro: recebe uma função `Post` injetada (Tauri no app, `fetch` do Node na bateria), monta fatos e ferramentas com os builders que as telas já usam e confere todo valor em R$ e % da resposta contra os textos de origem. A tela fica em `src/pages/Assistente.tsx` + `src/pages/assistente/`.

**Tech Stack:** Tauri 2 (Rust 2024), React 19 + TS, Vitest, llama.cpp `llama-server` (Metal no Mac, Vulkan + CPU no Windows), Qwen3 GGUF Q4_K_M. Crates novas só as que já estão no `Cargo.lock`: `sha2`, `libc` (macOS), `windows-sys` (Windows), e o `reqwest` reexportado por `tauri_plugin_http::reqwest`.

**Spec:** `docs/superpowers/specs/2026-10-30-ia-local-design.md`

## Global Constraints

- Repositório público: testes e bateria só com dados inventados (AAAA3, FIIA11, Banco Laranja). Commits **sem** Co-Authored-By.
- Nenhum dado financeiro sai da máquina: chamadas ao servidor local só pelo Rust com `reqwest::Client::builder().no_proxy()`; download só de URL `https://huggingface.co/`. Nenhuma permissão nova de HTTP no front.
- Nada da IA baixa ou sobe para quem não abre o Assistente; servidor e download só sob clique.
- A IA é só leitura: nenhuma ferramenta escreve no banco.
- Esquema: só migração nova `017_ai_insights.sql`; `SCHEMA_VERSION = 17`; `UPDATE meta … WHERE key = 'schema_version'`.
- Visual: `card`, `sum-row`, `kpis`, `Select`, lucide-react, tabular-nums. Sem `window.confirm`.
- Valores para o modelo saem sempre sem máscara (`plainBRL`); a máscara do olhinho é só na exibição.
- Recomendações só no nível de classe, nunca ticker. Rodapé fixo: "Sugestões automáticas a partir dos seus dados; não são recomendação de investimento."
- `src/ai/*.ts` (menos `server.ts`) não importa `@tauri-apps/*` nem `.tsx`, para rodar no Vitest/Node.
- Comandos: `npx vitest run <arquivo>`, `npx tsc --noEmit -p .`, `cargo test --manifest-path src-tauri/Cargo.toml` (precisa de `pnpm llama` antes, Task 2).

## Review Focus

1. Máquina de "16 GB" que o SO informa como 15,8 GiB → modelo médio; 8 GB informados como 7,8 GiB → leve. (Task 3, `pickModel`)
2. Olhinho ligado → o modelo recebe os valores reais e a tela mostra `R$ •••••`. (Task 3 `maskMoney`, Task 5 `plainBRL`)
3. Modelo escreve "R$ 1.235" ou "R$ 1.234" para R$ 1.234,56, "R$1.234,56" sem espaço, ou "12%" para 12,3% → conferido; "R$ 1.300" e "R$ 5 mil" sem fonte → não conferido. (Task 3, `unverified`)
4. Download interrompido → continua do `.part`; servidor que ignora `Range` → recomeça; SHA errado → apaga e avisa; servidor que morre ao subir → erro na hora, não 120 s depois. (Task 1)
5. Mês sem dados → `buildFacts` vazio e a tela diz que não há o que analisar, sem chamar o modelo; cotação nova a cada 15 min não marca os insights do mês como "desatualizado". (Task 5 + Task 7)

**Interfaces — Produces (comandos, campos camelCase via `#[serde(rename_all = "camelCase")]`):**
- `ai_hardware() -> Hardware { ramBytes: u64, arch: String, os: String, gpu: Option<Gpu { name: String, vramMib: u64 }> }` — RAM por `sysctlbyname("hw.memsize")` / `GlobalMemoryStatusEx`. GPU só no Windows: se `%SystemRoot%\System32\vulkan-1.dll` não existe → `None`; senão roda `llama-server --list-devices` e lê com `parse_devices`. Guardado no `State`.
- `ai_installed() -> Vec<{ file: String, bytes: u64 }>` — `.gguf` em `app_local_data_dir()/models/`.
- `ai_download(url, sha256, file, on_progress: Channel<{ received: u64, total: u64 }>) -> Result<(), String>` → valida `allowed_url`/`valid_model_file` e chama `download_to(url, sha, dest, cancel: &AtomicBool, progress: impl FnMut(u64, u64))`: `.part` + `Range: bytes=<n>-`; 200 trunca; fim → SHA-256 do arquivo e renomeia; errado → apaga e `"O arquivo baixado veio corrompido. Tente baixar de novo."`.
- `ai_cancel_download()` — flag; o `.part` fica.
- `ai_delete_model(file) -> Result<(), String>` — valida, para o servidor se usa esse arquivo, apaga `.gguf` e `.part`.
- `ai_start(file, ctx: u32) -> Result<(), String>` (async) — valida; mesmo arquivo rodando → `Ok`; senão para o anterior, porta livre de `TcpListener::bind("127.0.0.1:0")`, chave hex de 32 bytes (`aes_gcm::aead::OsRng`) passada por env `LLAMA_API_KEY` (nunca em argv), binário `current_exe().with_file_name(format!("llama-server{}", EXE_SUFFIX))` (Windows sem GPU: `llama-server-cpu`), `Stdio::null()`, no Windows `CREATE_NO_WINDOW` e Job Object com `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`; no Mac `// shortcut: se o app morrer sem RunEvent::Exit (panic=abort, crash) o servidor fica órfão; vigiar o pai se aparecer.` Depois espera `GET /health` a cada 500 ms até 200 (máx. 120 s), falhando na hora se `child.try_wait()` mostra que saiu: `"O modelo não conseguiu iniciar."`; tempo esgotado: `"O modelo não respondeu. Tente de novo ou troque de modelo em Configurações."`.
- `ai_post(path: String, body: String, on_chunk: Channel<String>) -> Result<String, String>` (async) — `POST http://127.0.0.1:<porta><path>` com `Authorization: Bearer <chave>`, cliente `no_proxy()`; sem servidor → `"O Assistente não está ligado."`. Se o corpo tem `"stream":true`, repassa cada pedaço por `on_chunk` (texto UTF-8 completo, com `take_utf8`) e devolve `""`; senão devolve o corpo. Status ≠ 2xx → `Err` com o corpo. Confere a flag de `ai_abort` a cada pedaço; cada chamada zera o timer de inatividade.
- `ai_abort()`, `ai_stop()`. Inatividade: tarefa (`tauri::async_runtime::spawn`) que a cada minuto para o servidor se o último `ai_post`/`ai_start` foi há ≥ 10 min.
- `shutdown(app)` — mata o filho.
- Puras, com teste: `parse_devices(out: &str) -> Option<Gpu>` (maior VRAM entre as linhas `Vulkan<n>: <nome> (<total> MiB, <livre> MiB free)`), `valid_model_file(name) -> bool` (`^[A-Za-z0-9._-]+\.gguf$`, sem `..`), `allowed_url(url) -> bool` (prefixo `https://huggingface.co/`), `server_args(model: &Path, port: u16, ctx: u32) -> Vec<String>` = `-m <model> --host 127.0.0.1 --port <port> -c <ctx> -np 1 --jinja --reasoning-budget 0 --no-webui` (sem `-ngl`: o padrão automático cabe a memória da GPU), `take_utf8(buf: &mut Vec<u8>) -> String` (devolve o prefixo UTF-8 válido e deixa no buffer o caractere cortado).

- [ ] **Testes** (`#[cfg(test)]`, async com `tauri::async_runtime::block_on`): `parse_devices` com GPUs de 4096 e 8192 MiB → 8192; sem `Vulkan` → `None`. `valid_model_file`: `"Qwen3-8B-Q4_K_M.gguf"` sim; `"../x.gguf"`, `"a/b.gguf"`, `"x.bin"` não. `allowed_url`: `https://huggingface.co/Qwen/…` sim; `http://huggingface.co/…`, `https://huggingface.co.evil.com/…` não. `server_args` tem `--host 127.0.0.1`, não tem `0.0.0.0` nem a chave. `take_utf8` com `"é"` cortado no meio devolve o prefixo e completa no próximo pedaço. `download_to` contra servidor de teste em `127.0.0.1` (TcpListener + thread): `.part` de 4 bytes manda `Range: bytes=4-` e o final tem o SHA certo; resposta 200 ao Range não duplica os 4 bytes; SHA errado → erro e nem `.gguf` nem `.part`.
